# 📊 Machine Learning Projects for OASIS INFOBYTE

A collection of beginner-to-intermediate Machine Learning and Data Analysis projects built using **Python**, **Scikit-learn**, **Pandas**, and **Jupyter Notebook**. This repository demonstrates the complete ML workflow—from data preprocessing and exploratory data analysis (EDA) to model training, evaluation, and visualization.

---

## 📚 Projects Included

| Project | Type | Description |
|---------|------|-------------|
| 🌸 Iris Flower Classification | Classification | Predicts Iris flower species using machine learning classification algorithms. |
| 📊 Unemployment Analysis | Data Analysis | Explores unemployment trends across India using statistical analysis and visualizations. |
| 🚗 Car Price Prediction | Regression | Predicts the selling price of used cars based on vehicle specifications. |

# 🛠️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/Machine-Learning-Projects.git
```

Move into the project directory

```bash
cd Machine-Learning-Projects
```

Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

Launch Jupyter Notebook

```bash
jupyter notebook
```
