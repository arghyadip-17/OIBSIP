# 📊 Unemployment Analysis with Python

A Data Analysis project that explores unemployment trends across India using Python. The analysis focuses on regional and temporal unemployment patterns with special emphasis on the COVID-19 period.

---

## 📌 Objective

Analyze unemployment data to identify:

- State-wise unemployment trends
- Monthly unemployment variations
- Regional differences
- COVID-19 impact on unemployment

---
