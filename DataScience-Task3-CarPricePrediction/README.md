# 🚗 Car Price Prediction using Machine Learning

A Machine Learning regression project that predicts the selling price of used cars based on multiple vehicle features such as brand, age, mileage, fuel type, transmission, engine specifications, and ownership details.

---

## 📌 Objective

Develop a regression model capable of estimating the selling price of a used car using historical vehicle data.

---
