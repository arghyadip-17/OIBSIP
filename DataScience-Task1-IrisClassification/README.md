# 🌸 Iris Flower Classification using Machine Learning

A Machine Learning classification project that predicts the species of an Iris flower using its physical measurements. The project compares multiple classification algorithms and selects the best-performing model.

---

## 📌 Objective

Build a classification model that accurately identifies Iris flower species:

- Setosa
- Versicolor
- Virginica

using flower measurements.

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 📂 Project Workflow

- Import required libraries
- Load the Iris dataset
- Perform Exploratory Data Analysis (EDA)
- Visualize data using:
  - Pairplots
  - Boxplots
  - Correlation Heatmap
- Feature Selection
- Train-Test Split
- Train multiple ML models
- Evaluate model performance
- Compare model accuracy
- Predict Iris species
